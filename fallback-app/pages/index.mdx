# AWS CI/CD Deployment Lab

Welcome to my CI/CD deployment lab!

This is a lightweight Next.js application that I deployed to demonstrate a complete CI/CD lifecycle.

### What is running here?
- **Server**: AWS EC2 t3.micro (Ubuntu)
- **Proxy**: Nginx
- **Process Manager**: Docker & PM2
- **Pipelines**: GitHub Actions

Check out the GitHub repository for the full source code and documentation.
